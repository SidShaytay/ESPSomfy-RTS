# v4.1.3 source checkpoint

Adds opt-in SDK task stack measurements and a separately enabled USB interface for automated stack qualification. Download-only audit staging uses the production HTTPS transport and image verifier, then releases its PSRAM buffer without flash admission. Ordinary firmware has neither audit instrumentation nor USB commands; task stack allocations are unchanged.

Host tests and a controlled development build passed. This source checkpoint is not a published binary release or completed live qualification. Follow #33 and docs/audits/stack-qualification.md for actual coverage and limits.
