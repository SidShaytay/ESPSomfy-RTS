# v4.3.1: Battery settings on the screen, and a fixed Firmware tab

This release follows v4.3.0 for the LILYGO T-Embed CC1101 and CC1101 Plus. Both boards use the same `lilygo-t-embed-cc1101` firmware, which includes the web interface.

## Fixed

- **The web UI's System → Firmware tab was unreadable in v4.3.0.** A grey layer covered the version details and the GitHub update section. The page now shows normally.

## Changed

- **Battery settings are now on the screen too**, under **System → Configure → Battery**. It shows the level and voltage and lists the charge limits; turn to one and press to apply it. 60% is marked as recommended for a controller that is always on USB.
- **In the web UI the battery moved** out of the Firmware tab. The level is in the header under Network and Channel, and the level and charge limit are under **System → Options → Battery**.
- A new [feature locations](../feature-parity.md) page lists where each feature is in the web UI and on the screen.

## Install

From v4.3.0 or another tagged v4.x LILYGO build, use the screen's GitHub updater (System → Maintenance → GitHub updates), the web updater, or a firmware-only upload. Settings, the charge limit and rolling-code counters are kept. Coming from another firmware, read [first installation](../first-install.md) first. Don't erase the flash or use a factory image.

The protocol is unchanged from v4.3.0.
