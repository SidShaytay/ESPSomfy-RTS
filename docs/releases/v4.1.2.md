# v4.1.2 — stack audit records at release log levels

Source checkpoint for issue #35. No GitHub binary release is published by this audit.

The optional stack probe now emits its structured records independently of info-level logging. Release builds use log level 2, which suppressed the 4.1.1 probe output; that image booted successfully but supplied no stack measurements. The normal firmware still omits the probe entirely.

The audit build now checks the emitted firmware for its unique record format and rejects a silent instrumented image. It retains the SSDP ownership/deadline fixes and stable update identity from 4.1.1. See the [stack audit](../audits/firmware-stacks.md) for verified results and remaining coverage limits.
