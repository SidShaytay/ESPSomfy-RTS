# v4.1.1 — network discovery stack ownership

Source checkpoint for issue #35. No GitHub binary release is published by this audit.

- SSDP UDP callbacks now hand copied requests to the main loop before device lookup, reply formatting and transmission. This removes the small UDP task's nested send path and gives delayed replies and USN scratch data one owner.
- Bounded queues reject stale lifecycle work, retain original multicast deadlines across queue residence and clock wrap, and reclaim expired duplicates.
- Optional stack instrumentation records task margins and sampling cost. It is disabled in normal builds; the audit image enables it and retains a stable update identity so GitHub update checks remain available.

The [stack audit](../audits/firmware-stacks.md) records measurements and coverage limits. Firmware-only updates require the [standard backup and flashing procedure](../flashing.md); no filesystem image or layout change is needed.
