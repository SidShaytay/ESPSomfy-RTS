# v4.1.0 — LILYGO LCD controls and bundled updates

This public release builds on cjkas v4.0.2 and the completed `main` integration for LILYGO T-Embed CC1101 and CC1101 Plus. Both boards use the shared `lilygo-t-embed-cc1101` image.

## Added

- Integrated 320×170 LCD with device/group controls, three shortcuts, room browsing, configuration, diagnostics, battery status and adjustable brightness/dim/sleep.
- Browser Appearance setting with System, Light and Dark choices, saved per browser.
- LCD GitHub updates using verified HTTPS, PSRAM-backed TLS/staging, exact image/profile/digest checks, boot-health confirmation and checked rollback.

## Changed

- One LILYGO firmware image embeds the matching web interface. Firmware and web UI update/roll back together. There is no separate LILYGO web/filesystem upload; private LittleFS data remains allocated.
- Local controls use the existing controller credentials. Numeric edits and update installation require review before applying.

## Fixed and hardened

- Retains cjkas’s asynchronous networking, radio scheduling/locking, RAM-based backup generation and restore-option fixes.
- Renders Wi-Fi names as text and validates SSDP bounds, backup record counts and supported radio frame lengths.
- Reserves integrated board pins, validates selected command identities and defers network discovery sends from Wi-Fi callbacks to the loop.

## Install without losing settings

Read [first installation](../first-install.md) before migrating from another firmware. A firmware-only upload preserves configuration on a verified matching layout. Older layouts need a USB plan that preserves authoritative configuration and current NVS counters; do not erase or use a factory image.

Engineering 4.9.x versions precede this public release in development history but sort higher numerically. The sole engineering controller needs a one-time manual firmware-only upload to v4.1.0. Future public releases advance from 4.1.0 normally; deleting engineering GitHub listings does not change installed versions.

This release uses protocol 2 and the cjkas-compatible Home Assistant integration, 3.0.0 or newer. Old ports 8080/8081 and legacy state HTTP routes are not supported. Generic ESP32 images retain their separate filesystem workflow; these LILYGO assets are not generic S3 images.

A physical LCD GitHub installation and state-preserving boot/readback succeeded during engineering qualification. Remaining physical controls, other-board coverage and combined-load/idle measurements remain tracked in [issue #33](https://github.com/SidShaytay/ESPSomfy-RTS/issues/33) and the [qualification plan](../lcd-completion-qualification.md).
